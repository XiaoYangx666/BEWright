## 文档维护规则

- 参数细节以 CLI 参考为主，内容字段以内容契约为主；工作流只串联步骤，避免复制整张参数表。
- 文档与运行结果不符时，核对对应 `src/cli/commands/`、公共类型和测试；不要依据旧报告修改当前实现。
- 所有命令示例默认在仓库根的 PowerShell 执行，先编译工具后用 `node dist/cli/index.js ...`；安装包提供 `bewright` 命令。`<id>`、`<name>`、`<世界目录>` 是占位符，需替换；命令中的 `demo-arch` 是源码仓库自带的示例。
- 变更命令行为时同步更新 CLI 参考和受影响工作流；变更公共类型时同步更新内容契约或 authoring 文档。
- 删除已经完成迁移的旧路径对照；仍被使用的兼容字段、历史交付记录与数据来源保留，并标明适用范围。
